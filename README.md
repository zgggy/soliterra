# Soliterra · 本地世界观写作平台

**一个本地优先（local-first）的长篇世界观创作平台。** 以纯 Markdown + 图片为数据源，一个 `.md` 即一条条目；
时间轴、目录树、关系图三视图并列，写作与考据同一处完成。无账号、无云端——数据在你自己手里，git 即历史。

> 仓库为本项目**纯代码**：不含任何世界观内容。世界（世界库）位于项目目录之外，见「世界库配置」。

## 快速开始

```bash
cd src
npm install          # 首次
npm run build:editor # 首次（预打包 CM6 编辑器；产物已随仓库提交，可跳过）
node server.js       # → http://127.0.0.1:4747
```

首次运行后在首页 `+` 卡向导里创建你的第一个世界（自动 `git init`）。

## 世界库配置（worldsDir）

世界观内容与本项目**分开放**。服务器按以下优先级解析世界库目录：

1. CLI 参数：`node server.js <worldsDir>`
2. 环境变量：`SOLITERRA_WORLDS=<worldsDir> node server.js`
3. 配置文件：复制 `soliterra.config.example.json` 为 `soliterra.config.json`，设置 `worldsDir`
   （相对路径按项目根解析；该文件已 gitignore，不会进仓库）
4. 默认回退：`src/worlds`

世界库目录中，**每个子文件夹 = 一个世界**（各自是独立 git 仓库，`<世界>/.soliterra/` 存索引，可删重建）。

## 功能

- **时间轴**（顶栏唯一全局元素）：`&s/&e` 覆盖条与 `&f` 旗标、模糊日期（`*`）、重叠堆叠（无自动缩放）、打开取景 1/3–2/3、起止标记、滚轮锚点缩放、拖拽平移、键盘（T/←→/±）、时代带、高度可拖至 **3/4 屏**（超过 2/3 屏时**本书全部条目上轴**，显示逻辑与常规完全一致）；
- **阅读**：双链/嵌入/反链、callout（作者/剧透等按视图分级）、`passage` 勘误（已证伪徽章+勘误行）、进度记忆、悬浮预览卡；
- **编辑**：CodeMirror 6 简化编辑器（装饰层：`&` 元数据芯片行、双链蓝、围栏角标；工具栏 12 命令；`[[` 补全；防抖 500ms 自动保存；极简档备选）；元数据结构化编辑（日期/枚举/标签/封面控件）；**图片管线**（粘贴/拖入上传、assets 缩略图选择器、编辑器内联缩略图、大图纸面）；**输入快捷格式**（`【【`→`[[|]]` 光标居中、括号自动配对、行首 `&`/`>`/`/` 菜单、粘贴净化）；**元数据抽屉**（编辑态顶条 chips 即点即改、逐键解释、`＋` 添加菜单）；
- **五 push 面板**：目录（可拖动增删改）· 世界（信息+设置+提交）· 全部书籍（分类过滤）· 关系图 · 工具箱；
- **关系图**：一跳邻里/全库图、力导向/按时间/按树分组三布局、`rel` 围栏强边、节点拖拽钉住、路径强调/中心化/框选、编辑保存增量刷新；
- **稍后阅读**：底部中央卡片集（扇形 ↔ 横排）；
- **工具箱**：一致性校验 lint（9 项）+ 日期归一/【【】】转链/拼写漂移/图片路径/正则替换/重名修复，扫描→diff→应用（自动备份）；
- **通用**：⌘K 全文检索（FTS5+中文兜底）与日期取景、导出（md/txt/EPUB/PDF）、git 历史纸面与回滚、仪表盘、Obsidian 导入、视图分级（作者/读者）、i18n（中/英，locales 自动注册）；
- **设计系统**：四条铁律（纯色直角矩形 / 图标无背景 / 1px 发丝线 / 排版即布局）、三档时长动画 + reduced-motion 降级。

## 项目结构

```
Soliterra/
├── 平台设计方案.md      # 整体设计（概念模型/数据层/架构/路线）
├── 功能设计.md          # 功能全量规格（§1–§19 + 审计表）
├── design.md            # 样式规范与三层组件清单（含 Motion 系统）
├── 全景时间轴与编辑器增强设计.md   # 进行中新需求规格（规划）
└── src/
    ├── server.js        # Fastify：REST + 静态 + 文件监听
    ├── lib/             # parser / indexer(SQLite FTS5) / render / vault(git) / tools
    ├── public/          # 零构建前端（vanilla ES modules + app.css）
    ├── editor/          # CM6 扩展源码（esbuild → public/js/vendor/）
    └── locales/         # 语言包（放新 json 即自动注册）
```

## 技术栈

Node.js · Fastify · better-sqlite3（FTS5 + JSON1）· chokidar（文件监听）· markdown-it · CodeMirror 6（esbuild 预打包，运行时零构建）；前端原生 ES modules，无框架。

## 数据与语法（要点）

- 一条目 = 一个 `.md`；`X.md` + `X/` 同名配对 = 可展开节点（书/子条目）；
- `&` 单字母元数据：`&s&e`（时间）`&t`（标签）`&f`（事件分类）`&a`（时代）`&n`（标题）`&p`（状态）`&v`（可见性）`&q`（可信度）`&m`（封面）；值空格分隔，可换行、任意位置；
- `[[双链]]` / `![[嵌入]]` / `> [!档案]` callout / ` ```event|rel|term|scene|passage ` 围栏——纯 Obsidian 兼容子集，格式不逼人改，工具替人改。

## 协作约定（三文档同步）

设计需求落笔时三份主文档**同步更新**：平台设计方案（架构融入）· 功能设计（交互规格）· design.md（组件与样式）；
进行中的新需求在《全景时间轴与编辑器增强设计.md》立档，实现后回填三主文档。`功能设计.md` §18 审计表 = 唯一待办池。
