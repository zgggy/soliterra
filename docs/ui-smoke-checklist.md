## 进入流

## 目录树
- [ ] 点有子条目的行 = 展开/收起（不导航）；点叶子 = 打开
- [ ] 同层拖动 = 重排序：落点半边出现**卡间间隙**指示线；拖后目录**不收起**；磁盘 `&r` 落盘

## 编辑器
- [ ] 进入编辑：打字 → 500ms 自动保存（顶缘状态条 `Saved`）
- [ ] 点工具栏按钮（H1/B…）**无报错**；点 `&` 行 = 光标就地编辑（不弹卡）
- [ ] 键入 `｜`/`“”` → 自动转 `|`/`""`；`「」` 保留
- [ ] 抽屉 chip 点开键编辑卡：日期输 `705.9.10` → 可直接确定 → 归一 `0705.09.10`
